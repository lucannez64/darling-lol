# Licensing and third-party material

`LICENSE` contains GPL-3.0, used for this project's original integration tooling. Patches to upstream code retain the original files' licenses and notices. Darling and its submodules include GPL, LGPL, APSL, BSD, Apache and other upstream licensing; consult each pinned repository before redistribution.

The manifest points to public upstream source repositories. This repository includes source differences and authored integration/research tools, not a copy of the upstream runtime, Apple's SDK binaries or Riot's client/game assets. Build artifacts and local installs are excluded.

Some compatibility tools refer to public API names and constants of the user's installed client. The client itself is not redistributed. Installation downloads from Riot's distribution service directly.

## Historical material

Earlier revisions of this repository included a third-party game logo and an embedded gameplay clip. Both were removed from the current tree; the current tree uses an original project mark and contains no gameplay media. Git history and third-party forks may still contain those earlier revisions. They are not part of the current project, are not licensed by this project, and should not be reused.
